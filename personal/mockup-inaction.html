Mock-up: "In action" status for My minutes

A task gets a third state between open and done. In action means you've started it, or it's waiting on a reply. It shows an orange half-filled box, an In action label and a light orange row. Below are two ways of setting it, so pick the one that suits how you work. Nothing here is live.

How you'd set it
AAutomatic from red text

As soon as part of a line is red, the line becomes In action. Ticking it still marks it Done. Take the red off (right-click › Plain) and it goes back to open.

  • No extra clicks: highlight the words, right-click, choose Red, as you do now.
  • Lines that already have red text become In action automatically.
  • Red used for emphasis only (not a status) would still mark the line In action.
BClick the box to cycle, with red as a shortcut

Clicking the box cycles Open → In action → Done. Right-clicking highlighted text adds Red + In action in one go. Red you add with plain "Red" stays just colour.
